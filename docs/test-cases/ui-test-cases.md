# UI Test Cases

## UI-001 — Регистрация нового пользователя

**Описание:** 
Регистрация нового пользователя с новыми данными

**Тестовые данные:**
- Name: Ivan
- Email: уникальный валидный email
- Password: qwerty
- Last name: Petrov
- Address: Lenina, 602, AO HiTich
- State: Russia
- City: Moscow
- Zipcode: 603022

**Шаги:**
1. Открыть страницу https://www.automationexercise.com/login
2. В поле "Name" ввести "Ivan"
3. В поле "Email address" ввести уникальный валидный email
4. Нажать "Signup"
5. Открывается расширенная форма регистрации
6. В поле "password" ввести "qwerty"
7. В поле "name" ввести "Ivan"
8. В поле "last name" ввести "Petrov"
9. В поле "address" ввести "Lenina, 602, AO HiTich"
10. В поле "State" ввести "Russia"
11. В поле "City" ввести "Moscow"
12. В поле "Zipcode" ввести "603022"
13. Нажать "Create account"

**Ожидаемый результат:**
Информационное сообщение: "ACCOUNT CREATED!"
